## Machine-readable SBOM, and how this file relates to it

WP-12 item 10 added `scripts/gen-sbom.mjs`, which generates `sbom/cyclonedx.json` (CycloneDX
1.5 JSON) and `sbom/licences.json` from `go.mod`, `go.sum`, `web/package-lock.json`, and the
installed module/package metadata. Re-run it with:

```bash
node scripts/gen-sbom.mjs          # regenerate
node scripts/gen-sbom.mjs --check  # fail if the checked-in output has drifted
```

The `--check` form runs in both `scripts/verify.sh` and `scripts/verify.ps1`, so the SBOM cannot
drift from the lockfiles without failing a gate.

**This Markdown file and the generated SBOM divide the work.** The SBOM is the complete,
machine-readable inventory: every module in the resolved Go graph and every resolved npm package
slot, each with an identified licence, an evidence tier, and its source hash. This file reproduces
licence TEXT, which is what a distribution has to carry and what a scanner cannot invent.

The WP-01 section below is unchanged, including its "Toolchain-only modules without downloaded
source directories are outside this inventory" caveat — that caveat was true when it was written.
WP-12 item 10 closed the gap it described: every module in the graph now has an entry, in the
"Go module graph, complete inventory" section at the end of this file. No entry was deleted or
rewritten.

### What the SBOM found

- **No AGPL, GPL, LGPL or SSPL dependency anywhere.** Reported identifications across all 130 Go
  modules: MIT (66), BSD-3-Clause (35), Apache-2.0 (14), BSD-2-Clause (8), ISC (4), Unlicense OR
  MIT (1), BSD-3-Clause AND MPL-2.0 (1), MPL-2.0 (1). Across 1,388 npm package slots: MIT
  (1,270), ISC (63), BSD-3-Clause (16), Apache-2.0 (12), MPL-2.0 (12), BSD-2-Clause (5),
  BlueOak-1.0.0 (2), 0BSD (2), and one each of Python-2.0, CC-BY-4.0, CC0-1.0 and Unlicense, plus
  two OR-expressions. The two MPL-2.0 entries and the single BSD-3-Clause-AND-MPL-2.0 entry are in
  the graph tier, not in `go build ./...`'s closure. MPL-2.0 is file-level copyleft and is not on
  AGENTS section 6's preferred list, so it is named here rather than left for a reader to find.
- **No unidentified licence.** Every component resolved to an identifier or an SPDX expression.
- **Two identifications were WRONG before they were checked**, and both are recorded because a
  detector that reports a licence is making a claim: `modernc.org/memory`'s LICENSE is
  BSD-3-Clause but was reported BSD-2-Clause (its third clause reads "Neither the names of the
  authors..."), and `hashicorp/golang-lru/v2` plus `cyphar/filepath-securejoin` were reported
  AGPL-3.0 because MPL-2.0's own text mentions the AGPL in ordinary sentence case. Both were found
  by reading the files, not by trusting the output. See `scripts/gen-sbom.mjs` for the patterns and
  for why the GPL-family markers are case-sensitive.
