# Clean Windows VM Acceptance Checklist (T25)

日期：2026-09-27。本清单对应审计 T25 的完成标准：干净 VM 安装、升级、卸载、
普通用户/管理员、中文/空格路径、WebView2 有无、断网、恢复、外部依赖缺失。
**每步留证**（日志 + 截图）是验收的一部分；没有留证的通过不记为 PASS。

## 前置

| 项 | 要求 |
|---|---|
| VM | 干净 Windows 11（或 10 21H2+）x64 快照，未装本应用与开发工具 |
| 工件 | 最新 NSIS 安装包 + 对应 `InfiniteAtelier.exe`。**当前可用工件（2026-09-27 本机重建，dirty 工作树）**：`build/bin/源铭振跃-amd64-installer.exe`（15,899,858 字节，SHA-256 `ba8d200470b3c2495fc4b155126a0923e1c77b94a6e45243320cc2d0a1db8f8e`）与 `InfiniteAtelier.exe`（33,962,496 字节，SHA-256 `635e66127e9b8886648d7ec843fd0a29e081fe708998c9420ee00964f985ef8f`）。若 T32 已推送并由 CI 重建，以 CI artifacts 哈希为准替换本行 |
| 留证目录 | VM 内 `C:\acceptance\`（截图/日志按步骤编号存放） |

## 1. 安装（普通用户）

1. [ ] 记录 VM 快照点 `pristine`。
2. [ ] 双击安装包，以**普通用户**身份安装（默认 per-user 路径）。
3. [ ] 截图：安装向导各页（含 LICENSE/THIRD_PARTY_NOTICES 所在安装目录确认——T30 声明文件必须出现在 `$INSTDIR`）。
4. [ ] 启动应用 → 设置→诊断：记录 Embedding 状态（应为 `not_configured`）与数据目录路径。
5. [ ] 留证：`%AppData%` 下应用数据目录结构截图。

## 2. 主旅程（安装态、联网）

1. [ ] 导入测试小说（`testdata` 中许可合规样本）→ 事件 → 剧本 → 分镜图。
2. [ ] 配置一个 provider（可指向本地 mock/假供应商），生成一段 TTS + 一张分镜图。
3. [ ] 导出一集 MP4（previs）。留证：MP4 可播放、manifest 存在。

## 3. 升级

1. [ ] 在已装旧版上运行新版安装包（同签名状态）。
2. [ ] 验证：项目数据保留（打开旧项目可见）；设置保留。
3. [ ] 留证：升级前后数据目录 diff。

## 4. 卸载

1. [ ] 从"设置→应用"卸载。
2. [ ] 验证：**项目数据目录默认不被删除**（审计要求"卸载不默认删项目"）；开始菜单/桌面快捷方式移除。
3. [ ] 留证：卸载后数据目录仍存在。

## 5. 路径与区域

1. [ ] 中文路径安装：`D:\测试 目录\` 下安装并启动成功。
2. [ ] 含空格路径：`C:\Program Files\Infinite Atelier\`。
3. [ ] 中文用户名账户下数据目录读写正常。

## 6. WebView2 有/无

1. [ ] 快照回滚 `pristine`，卸载 WebView2 Runtime（若可）或用" evergreen offline 安装包未装"的干净镜像。
2. [ ] 安装包应触发 WebView2 安装（`wails.webview2runtime` 宏）；断网时记录其降级行为与错误文案。
3. [ ] 留证：两种状态下的启动截图。

## 7. 断网

1. [ ] 断网启动已装应用：主旅程已产出的项目可打开，本地功能可用。
2. [ ] 断网下尝试生成任务：应得到明确错误（非挂起），任务进入可重试状态。
3. [ ] **已安装前提下离线可用**与**离线首次安装**（WebView2 缺失时）分别留证。

## 8. 外部依赖缺失

1. [ ] 移除/未装 ffmpeg（PATH 无）：导出应给出诊断文案（非崩溃），其余功能可用。
2. [ ] 无 ONNX 模型/运行时：Embedding 显示 `unavailable`/`not_configured`，且**项目文本不得外发**（无命名 provider 时记忆语义功能应显示不可用）。

## 9. 恢复

1. [ ] 制作备份（界面导出）→ 破坏性改动（新建测试项目）→ 恢复备份 → 数据回到备份点。
2. [ ] 恢复期间断电模拟（强杀进程）后重启：应用不进入不可恢复状态（safe mode 可恢复）。

## 记录
