# Product Metrics Protocol（RP-11.3，2026-09-28）

> 状态：**PROTOCOL——测量前的固定规则**。本文件在任何产品指标取样之前写定：
> 阈值、样本策略、分母、排除规则与失败分类在看到结果前冻结。先测量后改阈值的
> 报告不构成验收。
>
> STATUS T27 已有的 React 渲染数字（1000 节点整面重渲染 532ms、+1997 边
> 737.9ms）是**单机制预验收**，不替代本协议要求的打开 P95 或原生 VM 流畅度。

## 1. 测量环境与版本固定

| 项 | 规则 |
|---|---|
| 硬件 | 记录 CPU 型号/核数、RAM、磁盘类型（SSD/HDD）、OS 版本。结果只对同一硬件类可比较 |
| 构建版本 | 记录 commit hash 与 `wails build` 产物 SHA-256；每次构建变化后全部指标重取 |
| 冷/热启动 | 冷启动 = 进程首次启动（重启系统后）；热启动 = 同一会话第二次启动。两者分别报告，不得混合 |
| 数据集 | 使用 testdata/canary-drama 固定 fixture（32,736 字/5 章）与脚本化生成的 100k 字合成语料、10k 素材、500 任务——均入库后重启再测（排除迁移噪声） |
| 排除规则 | 首次预热运行丢弃；病毒扫描/索引进程提示后重测一次；仍异常记为失败而非丢弃 |
| 失败分类 | timeout / error / crashed 分别计数，全部计入分母（失败不是"无样本"） |

## 2. PRD §14 产品指标（分母固定）

| 指标 | 分母 | 通过阈值 | 测量方法 |
|---|---|---|---|
| 新用户导入→骨架 | 尝试导入的独立用户数（含放弃者） | ≥90% | 诊断事件计数：import_completed→skeleton_approved 转化 |
| 恢复（强制关闭后） | 强杀进程次数 | ≥95% | AC-E2E-003 同场景：重启后项目/运行/任务三态读回 |
| 连续性定位 | 出现连贯性问题的镜头数 | ≥90% | 质量中心 finding→entity 跳转命中 |
| 迁移节点/边不丢失 | 迁入的节点+边总数 | 100% | legacy importer 计数比对（既有测试断言） |
| 备份泄漏（密钥） | 随机抽取的普通备份文件数 | 0 | 备份扫描（credential shapes）全量断言 |
| 有效操作步骤 | 每任务的操作点击/按键数 | 对照基线报告 | 手动走查记录，不设硬阈值 |

## 3. PRD §14 质量指标（Mock 只证机制）

| 指标 | 分母 | 通过阈值 | 备注 |
|---|---|---|---|
| 首次 Schema 校验通过 | 首次产出即校验的文档数 | ≥90% | deterministic Mock 的 100% 只证明机制工作，**不宣称真实模型成功率**——真实样本须 RP-11.2 授权后另取，独立标注 |
| 一次修复后通过 | 首次失败的文档数 | ≥98% | 同上 |
| 审核实体定位 | 审核报告的 finding 数 | ≥95% | finding→entity_id 非空且可解析 |
| 任务/文件一致 | 成功任务数 | 100% | result 引用的 file_objects 行必在 |
| 幂等重复资产 | 重复收集请求数 | 0 | CollectJobResult duplicate 路径计数 |

## 4. 性能采样规则

| 项 | 规则 |
|---|---|
| 样本数 | 每场景 ≥30 次（P95 需要）；1000 节点画布场景 ≥10 次人工手势 |
| P95 口径 | 排序后第 95 百分位（ceil(0.95×n)-1），不含丢样本 |
| 项目打开 P95 | <3s（PRD §14）；从点击项目到首帧渲染完成 |
| 普通 DB 命令 P95 | <100ms；GetProject/ListEpisodes 等绑定调用页面内计时 |
| 高频 Job events | 注入 ≥50 events/s；断言合并后普通进度 UI 写入 ≤10 次/s，且成功/失败/取消**终态不被节流吞掉**（终态事件必达） |
| 长运行内存 | 30 分钟批量生成会话，RSS 增长 <500MB 且无无界增长趋势 |

## 5. 报告与局限

- 结果记 `docs/implementation/product-metrics-results.md`：每指标给出
  numerator/denominator、原始样本的脱敏摘要、硬件/版本、失败分类计数。
- 样本不足的指标记 **未验收**（不虚构统计把握度）。
- Mock 指标与真实模型指标分开列示，永不合并成一个百分比。
